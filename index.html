🛫 桃園出境｜11/11 深夜

  1. 11/11 23:50前後到桃園T1，查看ZE984報到櫃台。
  2. 護照／機票 → 托運行李 → 領登機證。
  3. 安全檢查 → 台灣出境查驗 → 找登機門。

🛬 金海機場入境

  1. 06:05抵達金海機場國際航廈，跟 Arrivals／Immigration 指示走。
  2. 出示護照、依當時規定辦理入境審查（必要時e-Arrival Card）。
  3. 領行李 → 海關 → 出關。
  4. 開通SIM/eSIM → 測試網路 → ATM／現金 → 叫車。
  5. 目標08:30左右到飯店寄放行李；視現場延誤彈性調整。

🚇 最常用的三條交通路線

  1. 南浦 → 海雲台：南浦站搭1號線至西面 → 轉2號線往萇山方向，海雲台站下車。
  2. Centum → 南浦：Centum City站2號線至西面 → 轉1號線南浦站。
  3. 田浦 → 廣安里（雨天備案）：田浦站搭2號線到廣安站 → 步行約10–15分鐘至沙灘。

實際車次、站口、時間以 NAVER Map 現場導航為準；海岸及文化村區域計程車較省力。

🛫 11/15 回程金海機場

建議16:00前從南浦洞出發，17:15左右抵達國際航廈；確認台灣虎航IT607報到櫃台 → 行李規定／退稅 → 託運 → 安檢 → 出境查驗 → 登機門。20:50起飛、22:30到桃園T1。報到與登機截止時間請以航空公司實際通知為準。

📶 網路及使用方式

  1. 出發前確認手機支援eSIM及方案有效天數（11/12～11/15）。
  2. 在台灣有網路時安裝eSIM，依業者指示於韓國啟用。
  3. 抵達後設定韓國eSIM為行動數據；避免台灣門號產生意外數據漫遊。
  4. 安裝 NAVER Map、Papago、k.ride；儲存飯店韓文地址。
  5. 可購買交通卡並儲值，準備小額韓元現金。
